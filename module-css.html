Módulo 1: ¿Qué es CSS?

CSS significa Cascading Style Sheets. Se utiliza para dar estilo visual a los elementos HTML.

Por ejemplo, puedes cambiar el color, la fuente, el tamaño o la posición de los elementos.

        p {
          color: blue;
          font-size: 18px;
        }

Este es un texto con CSS aplicado.

Módulo 2: Selectores básicos

Con CSS puedes seleccionar elementos por su etiqueta, clase o id.

  • p { ... }: selecciona todos los párrafos
  • .clase { ... }: selecciona elementos con una clase
  • #id { ... }: selecciona un elemento con id específico
        .caja {
          background: lightblue;
          padding: 10px;
        }
Caja con clase .caja

Módulo 3: Bordes y márgenes

Podemos definir bordes, espacio interno (padding) y externo (margin).

        div {
          border: 2px solid black;
          padding: 10px;
          margin: 20px;
        }
Caja con borde, padding y margen

Módulo 4: Colores y fondos

Podemos aplicar colores al texto, fondo o bordes con CSS.

        h1 {
          background-color: yellow;
          color: darkred;
        }

Título con fondo amarillo

Módulo 5: Transiciones básicas

Con CSS puedes hacer animaciones sencillas usando transition.

        button {
          background: blue;
          transition: background 0.3s ease;
        }
        button:hover {
          background: green;
        }
