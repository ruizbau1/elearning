Módulo 1: ¿Qué es HTML?

HTML significa HyperText Markup Language. Es el lenguaje que usamos para darle estructura a una página web.

Por ejemplo, si queremos mostrar un título, usamos la etiqueta <h1>, que indica un encabezado principal.

        <h1>Hola Mundo</h1>

Hola Mundo

Módulo 2: Estructura básica de una página HTML

Una página HTML empieza con <!DOCTYPE html> y se organiza en <html>, que contiene:

  • <head>: información para el navegador (título, estilos, etc.)
  • <body>: lo que ves en pantalla (textos, imágenes, botones, etc.)
        <!DOCTYPE html>
        <html>
          <head><title>Mi Página</title></head>
          <body><h1>Hola Mundo</h1></body>
        </html>

Hola Mundo

Módulo 3: Encabezados HTML

HTML tiene seis niveles de encabezados:

  • <h1>: título más importante
  • <h6>: texto más pequeño
      <h1>Título principal</h1>
      <h2>Subtítulo</h2>
      <h3>Sección</h3>
      <h6>Texto pequeño</h6>

Módulo 4: Textos, enlaces e imágenes

HTML permite mostrar contenido en la pantalla mediante etiquetas como:

  • <p>: crea párrafos de texto
  • <a>: crea enlaces que puedes hacer clic
  • <img>: muestra imágenes

Ejemplo:

        <p>Bienvenido a mi web</p>
        <a href="https://google.com">Ir a Google</a>
        <img src="foto.jpg" alt="Foto de ejemplo">

Bienvenido a mi web

Ir a Google

Módulo 5: Listas en HTML

HTML tiene 2 tipos de listas:

  • <ul>: lista no ordenada (con puntos)
  • <ol>: lista ordenada (con números)

Dentro de cada lista usamos <li> para cada elemento.

        <ul>
          <li>Manzana</li>
          <li>Banana</li>
        </ul>
        <ol>
          <li>Paso 1</li>
          <li>Paso 2</li>
        </ol>
  • Manzana
  • Banana
  1. Paso 1
  2. Paso 2

Módulo 6: Formularios en HTML

Los formularios sirven para que el usuario ingrese datos como nombre, correo, etc.

Se componen de campos como:

  • <label>: indica qué debe escribir el usuario
  • <input>: campo donde se escribe
  • <button>: botón para enviar
        <form>
          <label>Nombre:</label>
          <input type="text">
          <button>Enviar</button>
        </form>



Módulo 7: Comentarios y buenas prácticas

En HTML puedes escribir comentarios que solo tú verás (no el usuario).

Sirven para dejar notas o recordatorios. También es importante mantener tu código bien indentado (ordenado).

        <!-- Esto es un comentario -->
        <p>Este texto sí se verá</p>
